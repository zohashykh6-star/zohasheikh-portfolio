ZOHA SHAIKH PORTFOLIO

1. Extract this ZIP using Windows Extract All.
2. Keep index.html, Zoha_Shaikh_CV.pdf, and email-server-front-end-source.zip together in this folder.
3. Double-click index.html to open the portfolio.
4. The View CV button opens Zoha_Shaikh_CV.pdf in a new browser tab.
5. The Email Server project source link downloads email-server-front-end-source.zip.

If opening the portfolio from a temporary ZIP preview, extract it first.
